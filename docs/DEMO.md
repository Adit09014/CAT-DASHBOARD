# Demo

The demo is deterministic and repeatable.

## Story Beats

1. Safety gate blocks an unsafe start when the seatbelt is not fastened.
2. Advancing telemetry raises idle time above the operator baseline.
3. What-if simulation shows how changed inputs affect estimated duration and fuel.
4. Predictive safety simulates future machine/object trajectory conflicts.
5. Training search accepts machine-related queries and rejects irrelevant ones.
6. Training completion records a before/after metric.
7. Demo reset restores the hero scenario for repeatable presentations.
